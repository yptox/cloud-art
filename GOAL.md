# Goal: Nubilous → autonomous ambient sky

Transform `nubilous.html` (yptox/cloud-art) from a slider-driven instrument into a zero-UI generative broadcast: a cloud simulation that runs itself and stays fascinating indefinitely. Public face = fullscreen sky, no chrome, cursor fades. `i` toggles a phosphor telemetry line (station, cloud taxonomy, reading name); backtick opens the old control panel as a hidden debug instrument. Config via URL params (?seed, ?place, ?mute). Keep: single self-contained HTML, phosphor-terminal aesthetic, seeded reproducibility (default 1802), honest physics (LCL cloud base, layered wind shear, Beer-Lambert + Henyey-Greenstein lighting).

**Phase 1 — Ambient shell.** Hide UI. Autonomous parameter drift via layered meta-noise with distinct time constants (turbulent churn: seconds; coverage: minutes; regimes: tens of minutes) + compressed diurnal cycle (~1 day per 25 min). Autonomous camera with a shot grammar — horizon gaze, underside crawl, rise-through-cloudbase whiteout-and-emerge, tower orbit, synoptic pull — slow drifts, occasional cuts; choose shots by sampling the density field for where the action is. Ships as: the piece just runs.

**Phase 2 — The conductor.** Replace aimless drift with frontal dramaturgy: a virtual 2D pressure map with drifting low-pressure centers; the viewpoint is a fixed station systems sweep across. Warm-front sequence (cirrus → cirrostratus → altostratus → nimbostratus rain → clearing), then cold-front towers and squally showers; wind veers/backs with passage. All parameters derive from this one coherent driver. Time dilation: slow during events, fast through lulls.

**Phase 3 — Convective life.** CPU-tracked cell entities over the noise substrate: coverage kernels with age-based life cycles (turret rises, matures, rains out, collapses). Feedback rules: a raining cell drops a cold pool; the gust front at its rim triggers new cells nearby → emergent squall lines and storm trains. Replace uniform advection with a curl-noise wind field so cloud masses rotate, stretch, and shear apart.

**Phase 4 — Cycle of readings.** Same density field, drifting projections, choreographed crossfades / wind-direction wipes; weather can force a reading (storm peak → Sky). Readings: Sky (physical, home key); Synoptic (existing isopleth terraces); Transect (vertical slice, filled contour bands); Streamlines (ribbons integrated through the layered wind, altitude-colored); Meteogram (overhead column scrolled as a time–height score); Census (density-sampled point swarm, lit by the same march); Engraving (cross-hatching along wind, density = optical depth); Terminal (CP437 phosphor glyph quantization); Taxonomy (real-time Latin labels — Cumulus mediocris, Cumulonimbus incus — with leader lines).

**Phase 5 — Phenomena, sound, roaming.** Rare condition-gated events: crepuscular rays (broken cover + low sun), 22° halo (cirrostratus veil), cloud-edge iridescence, rainbow (sun < 42° + rain opposite), interior night lightning in cumulonimbus, correct-phase moon, sunset virga. Generative audio (muted until click): filtered wind noise tracking wind speed, granular rain, thunder with distance-correct delay. Globe-roaming mood: every ~10 min drift to a real place via Open-Meteo (live layered cover + winds, local solar time), crossfade, field-recording caption ("Reykjavík, 04:12, drizzle"); variants: follow the terminator (perpetual golden hour), follow the storms (codes ≥ 80). Offline falls back to the synthetic conductor.

**Process constraints:** each phase leaves a working piece committed and pushed to `claude/cloud-simulation-web-mv29z7`; verify headlessly (Playwright + swiftshader Chromium) with screenshots across hours/regimes/readings before each push; update README and philosophy/nubilous.md when the transformation completes.
